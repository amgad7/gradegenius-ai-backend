📊 Purpose

This dataset serves as a benchmark to measure the accuracy of the GradeGenius AI system. Each row contains an essay with known errors and the expected corrections, allowing us to compare AI output against ground truth.

🤖 AI Model

The system uses Google Gemini 2.0 Flash, a pre-trained Large Language Model (LLM) accessed via API. The model was not trained locally — it is used as-is with custom prompt engineering to detect spelling, grammar, and vocabulary issues.

📏 Evaluation Metrics

Accuracy: Percentage of correct detections.
Precision: How many flagged errors are real errors.
Recall: How many actual errors were found.
Measured by comparing AI output to the expected columns below.
